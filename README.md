SOLMAR HEAT is an original open-world crime game set in the sun-soaked fictional city of Solmar Bay: explore the city on foot and by car, steal cars, outrun the Solmar PD through a five-star wanted system, and finish three story jobs as getaway driver Mara Voss. Built with three.js as static files — no build step, no network, just open game/index.html and play.

## Run it

```sh
node serve.ts  # then open http://localhost:8080
```
